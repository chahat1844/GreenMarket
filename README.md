# 🌱 Green Market

**Green Market** is a web-based agricultural marketplace platform designed to connect farmers directly with buyers, eliminating middlemen and ensuring fair pricing. The platform also provides additional services such as equipment rentals, cold storage booking, real-time market prices, and information on government schemes to empower farmers through technology.

---

## 🚀 Features

### 🛒 Direct Farmer-to-Buyer Marketplace

* Connect farmers directly with consumers and businesses.
* Reduce dependency on intermediaries.
* Enable transparent pricing and better profits for farmers.

### 📊 Real-Time Market Prices

* View updated agricultural commodity prices.
* Help farmers make informed selling decisions.

### ❄️ Cold Storage Booking

* Search and book nearby cold storage facilities.
* Reduce post-harvest losses through efficient storage management.

### 🚜 Equipment Rental Services

* Browse and rent agricultural machinery and equipment.
* Provide affordable access to modern farming tools.

### 🏛️ Government Schemes Information

* Access details about agricultural schemes and subsidies.
* Improve awareness of available support programs.

### 🌐 Multilingual Support

* User-friendly language selection.
* Supports English and Hindi for wider accessibility.

### 🔐 User Authentication

* Secure login and registration system.
* Personalized user experience.

## ⚙️ Installation and Setup

### Prerequisites

* Web Browser (Chrome, Firefox, Edge)
* Visual Studio Code (Recommended)
* Git (Optional)

### Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/GreenMarket.git
cd GreenMarket
```

### Run the Project

#### Option 1: Using Live Server (Recommended)

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click on `index.html`.
4. Select **Open with Live Server**.

The application will open automatically in your browser.

#### Option 2: Using Python HTTP Server

```bash
python -m http.server 8000
```

Open:

```
http://localhost:8000
```

in your browser.

## 🎯 Problem Statement

Farmers often face challenges such as:

* Dependence on middlemen resulting in lower profits.
* Limited access to storage facilities.
* Lack of awareness about government schemes.
* Difficulty accessing equipment and real-time market information.

**Green Market** addresses these challenges by providing a unified digital platform that empowers farmers and improves market transparency.
